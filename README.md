# 墨猫 Mocat

一只住在安卓手机屏幕边上的水墨小猫。

- 平时趴在屏幕边上探头，按住可以拖到别的位置
- 轻点它跑出来，点哪儿它去哪儿，一路留下墨爪印
- 它出来时长按屏幕某处，它会走过去帮你按一下
- 长按它弹出指令框，可以打字或语音：打开应用、返回、回桌面、滑动、点击屏幕上的文字、输入文字、读屏幕、手电筒、音量、音乐、打电话、发短信、提醒、闹钟、计算……

## 下载安装

每次推送到 `main`，GitHub Actions 会自动打包，APK 放在仓库的 **Releases** 里：

`https://github.com/<你的用户名>/<仓库名>/releases/latest/download/mocat.apk`

## 首次设置

1. 打开墨猫，点「去开启」，在无障碍里打开墨猫。开关是灰的：应用信息 → 右上角 ⋮ → 允许受限制的设置。
2. 允许忽略电池优化；国产手机还要在手机管家里允许自启动、后台不限制。
3. 可选：授权电话和通讯录，说「打电话给妈妈」就能直接拨出。

## 技术说明

- 纯 Java、无第三方依赖，minSdk 26（安卓 8.0），targetSdk 34
- 猫画在无障碍悬浮层（`TYPE_ACCESSIBILITY_OVERLAY`）上，所以不需要悬浮窗权限
- 没有联网权限，屏幕内容只在执行指令时读取
- `mocat.keystore` 是本项目自带的签名文件，保证每次打包签名一致、可以覆盖安装；它不保护任何秘密，如果要上架应用市场，请换成你自己的签名
